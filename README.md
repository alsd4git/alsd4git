# Alessandro Digilio

Developer by day, Android enthusiast in my spare time. I maintain practical open-source tools for self-hosting, automation, infrastructure, and everyday developer workflows.

## Featured projects

- [Immich Motion Photo Cleanup](https://github.com/alsd4git/immich-motion-photo-cleanup): audit Motion Photo duplicates with byte-level evidence and a separate, opt-in trash workflow.
- [Octi for Home Assistant](https://github.com/alsd4git/octi-home-assistant): community Home Assistant integration for the encrypted Octi ecosystem.
- [mtls-cli](https://github.com/alsd4git/mtls-cli): issue and package mTLS client certificates with Smallstep CA.
- [Homelab Compose Stacks](https://github.com/alsd4git/homelab-compose-stacks): curated Docker Compose stacks and operational guides for a self-hosted homelab.
- [sonarr-lang-checker](https://github.com/alsd4git/sonarr-lang-checker): find inconsistent audio-language coverage in Sonarr v4.
- [dotfiles](https://github.com/alsd4git/dotfiles): Bash and Zsh setup for macOS and Debian/Ubuntu, with a guided installer and developer tooling.

## More tools

- [Nginx Proxy Manager SSL CLI](https://github.com/alsd4git/nginx-proxy-manager-ssl-cli): harden proxy-host SSL and security settings from the command line.
- [list-macOS-apps](https://github.com/alsd4git/list-macOS-apps): inventory installed macOS applications from the terminal.
- [h388x-cli](https://github.com/alsd4git/h388x-cli): inspect and manage supported TIM HUB+ ZTE H388X router firmware.
- [MySQL Schema Diff](https://github.com/alsd4git/mysql-schema-diff): normalize and compare MySQL `CREATE TABLE` dumps.
