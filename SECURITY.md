# Security policy

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/alsd4git/alsd4git/security/advisories/new).
Do not disclose exploit details or sensitive data in public issues or pull requests.

Include the affected commit or version, expected impact and minimal reproduction
steps. Use synthetic examples and redact screenshots and logs. If your own
credential was exposed, revoke or rotate it. Report credentials you do not control
promptly and privately; do not use or attempt to revoke them.

## Scope

This repository contains profile documentation, not a versioned software product.
Reports should concern exposed credentials or unsafe content in this repository.
Issues in linked projects belong with their respective maintainers.
Reports are handled on a best-effort basis without guaranteed response times.
